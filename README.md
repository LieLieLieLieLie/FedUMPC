# FedUMPC

Federated Uncertainty-Aware Model Predictive Control for Heterogeneous Internet of Vehicles.

- `R0/`: archived previous repository version.
- `R1/code/`: analytical closed-loop simulations, federated learning, statistics and plots.
- `R1/MuJoCo/`: independent MuJoCo 3.11.0 validation and trajectory plots.

The R1 distribution contains source and frozen input protocols only. It omits
checkpoints, result tables, traces, figures and caches. All simulation inputs
are generated by the code; the protocol files fix the scene seeds. License
terms are in the repository's LICENSE.

## Analytical experiments

Use Python 3.10 and install `R1/code/requirements.txt`. The paper experiments
used NumPy 1.26.4 and PyTorch 2.0.1 (CUDA 11.8 build). Set
`PYTHONHASHSEED=0` before launching Python. In `R1/code`, choose a new
directory outside the source tree (the following paths are examples):

```powershell
$env:PYTHONHASHSEED = '0'
$run = Join-Path (Get-Location).Path '../../fedumpc_runs'
python reproduce.py run train-predictors --workspace $run --fresh
python reproduce.py run common --workspace $run
python reproduce.py run prototypes --workspace $run
python reproduce.py run prototype-summary --workspace $run
python reproduce.py run learners --workspace $run
python reproduce.py run matched-ci --workspace $run
python reproduce.py run ablation --workspace $run
python reproduce.py run uncertainty-diagnostics --workspace $run
python reproduce.py run uncertainty-controls --workspace $run
python reproduce.py run diagnostics --workspace $run
python reproduce.py run robustness --workspace $run
python reproduce.py run wind --workspace $run
python reproduce.py run wind-summary --workspace $run
python reproduce.py run prototype-disturbances --workspace $run --stage-args aekf
python reproduce.py run prototype-disturbances --workspace $run --stage-args cbf
python reproduce.py run ensemble-margin --workspace $run
python reproduce.py run ensemble-summary --workspace $run
python reproduce.py run federation --workspace $run --stage-args development
python reproduce.py run federation --workspace $run --stage-args evaluation
python reproduce.py run prediction-horizon-reference --workspace $run
python reproduce.py run prepare-figure-data --workspace $run --stage-args common
python reproduce.py run prepare-figure-data --workspace $run --stage-args robust
```

The same workspace is reused so each stage sees checkpoints and records
generated by preceding stages. An interrupted stage can be run again. See
`python reproduce.py list` for the available stages. The manuscript's
historical horizon diagnostic uses the explicit reference command above;
`prediction-horizon` instead uses the final controller's trust scale.

## MuJoCo and plots

In `R1/MuJoCo`, install `requirements.txt` and run the following commands:

```powershell
python run_r1.py final
python run_r1.py scene
python r1_external_prototypes.py
```

These produce the base and prototype records for the 12-scene cross-check
and the eight-controller trajectory figure. To render the analytical and
MuJoCo figures after the preceding stages, return to `R1/code` and run:

```powershell
python reproduce.py figures --workspace $run --output ../../fedumpc_figures
```

Install Times New Roman if matching the manuscript figure typeface is
important. Figures and tables are rebuilt from the current run. Timing and
aggregates can differ across hardware or software environments; previously
reported machine-specific aggregate overrides are not distributed.
